    # Simple Calculator

## Description

Simple Calculator is a basic Python project that performs different mathematical operations based on the user's choice.

This project was created to practice Python basics such as functions, loops, conditional statements, user input, and exception handling.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Modulus
* Power
* Exit option
* Handles invalid numeric input
* Handles division by zero
* Handles modulus by zero

## Technologies Used

* Python

## How to Run

1. Install Python on your computer.
2. Download or clone this project.
3. Open the project folder in a terminal or command prompt.
4. Run the Python file.

Example:

```bash
python calculator.py
```

## Exception Handling

The project uses exception handling to prevent the program from crashing when the user enters invalid input or tries to perform an invalid mathematical operation.

Examples:

* `ValueError` – handles non-numeric input.
* `ZeroDivisionError` – handles division or modulus by zero.
